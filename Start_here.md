Systems Kit


Welcome.


Systems Kit is a small collection of portable tools for thinking, coordination, and care.


It is designed to be copied, forked, challenged, remixed, or ignored.


Nothing here asks for allegiance.
Nothing here asks to become your worldview.


Take what is useful.
Leave what isn't.



What you'll find


core/
The primary reference material.
Read these if you want the complete framework.


cards/
Short versions for everyday use.
Start here if you only have five minutes.


diagnostics/
Ways to notice recurring patterns and failure modes.


governance/
Design principles for keeping projects healthy without becoming institutions.


examples/
Tiny demonstrations showing how the ideas look in practice.


archive/
Older work and historical versions.
Useful for history, not required for understanding the current material.



A simple promise


This repository tries to produce tools that remain useful even when you disagree with them.


If an idea survives questioning, keep it.


If it doesn't, improve it or throw it away.


Forking is success.



Open Window


There is no obligation to agree.


There is no obligation to contribute.


There is no obligation to stay.


You're welcome to read, ask questions, borrow an idea, improve one, or quietly leave with something that helps.


If you leave with one useful tool and one good question, this repository has done its job.
