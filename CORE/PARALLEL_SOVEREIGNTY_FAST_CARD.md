PARALLEL SOVEREIGNTY — FAST CARD

Status: Portable patch

Tagline: Distinct functions. No rank. No throne.

---

Core Read

O₁ ‖ O₂ ‖ O₃

Multiple origins may operate in parallel.

They are not:

ranked layers
stages of development
command roles
subordinate copies

Each origin remains sovereign.

---

Notation

Subscript = which origin.
O₁ O₂ O₃ — parallel. Carries no sequence.

Prime = how many returns deep.
O′ O″ — temporal. Carries no rank.

Both compose.
O₂″ = second origin, two passes in.

Loop: O → R → S → T → S′ → R′ → O′

Every symbol advances together.

---

Domain Rule

O ≠ R ≠ S ≠ T

O, R, S, and T remain distinct in function.

Distinct does not create rank.

No domain is above another.
No domain is below another.

Roles may rotate without creating hierarchy.

Rotation gets a cadence — not a veto, not a whim.

---

Relation Rule

R mediates.

R does not rule.

R may translate, pace, frame, route, or support contact.

The seat is structural. The occupant is not.
You can thin R. You cannot zero it.

R remains:

replaceable
non-owning
non-identity-bearing

R gets a chair, not a throne.

"The mediator's role is replaceable, not control authority."

---

Parallel Sovereignty Test

Can each origin speak without permission?

Can the mediator be replaced?

Can roles rotate without becoming rank?

Can structure change?

Can origin update after return?

Can anyone exit without punishment?

Does the loop return with more agency — or less?

Then ask when:

When did a role last actually rotate?
When was R last actually replaced?

Permission without exercise is the common failure.

Tests exist to break the card, not defend it.

---

Failure Signals

Grip:

Crown — one node becomes superior.
Capture — R becomes required.
Bypass — mediation goes unaccountable and gets called directness.
Fusion — distinct functions collapse together.
Rigidity — O cannot update.
Stagnation — S cannot change.
Distorted Return — the loop comes back with less room.

Slack:

Dissolution — nothing is permitted to hold.

Exitable is not weightless.
Every guard has an overdose state.

Room Condition (ZPR)

coercion = 0
ownership = 0

Exit valid.

This describes a room condition, not a guarantee.

If force is required to preserve the arrangement, sovereignty has already failed.
