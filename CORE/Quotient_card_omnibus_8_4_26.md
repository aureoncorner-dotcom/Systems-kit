## CORE CONSTRUCTION

Start with honest bounded measurable functions:

\[
B(X,\Sigma)=\{f:X\to\mathbb C : f\text{ measurable and bounded}\}.
\]

Represent them on \(L^2(X,\mu)\):

\[
\pi(f)=M_f,
\qquad
(M_fg)(x)=f(x)g(x).
\]

The representation is a contractive unital \(*\)-homomorphism, but for arbitrary measures it may not be faithful.

\[

**Counter-witness:** let \(X=[0,1]\sqcup\{p\}\) with \(\mu(\{p\})=\infty\). Then \(L^2(X,\mu)\cong L^2[0,1]\), so

\[

M_{\chi_{\{p\}}}=0.

The infinite atom has mass but no finite witness-handle.
